# Photos

Until real photos are added, every image on the site is an illustrated placeholder.

To use a real photo, put it here (for example `public/images/indonesia/raja-ampat.jpg`)
and set the `image` field on the matching data item:

- Country hero and card: `image` in `src/data/countries/list.ts`
- Dishes: `image` in `src/data/countries/<country>/foods.ts`
- Destinations and souvenir photos: `image` in `src/data/countries/<country>/explore.ts`

Use landscape photos around 1600 px wide, compressed to under 300 KB, and only
photos you have the rights to use (your own, the booth team's, or openly licensed).
